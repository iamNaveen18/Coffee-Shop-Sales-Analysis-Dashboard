# ☕ Coffee Sales Analysis Dashboard  

## 📌 Project Overview  
The **Coffee Sales Analysis Dashboard** is an interactive Excel-based data analytics project designed to analyze coffee shop sales performance and business trends. This dashboard transforms raw sales data into meaningful insights using dynamic visualizations, KPI tracking, and interactive filters.  

The project helps businesses monitor sales growth, customer purchasing behavior, product performance, and location-wise sales distribution for better decision-making.  

---

## 📊 Dashboard Highlights  
- Total Quantity Sold Analysis  
- Total Transactions Tracking  
- Revenue Performance Monitoring  
- Top 10 Products by Quantity Sold  
- Location-wise Sales Distribution  
- Hourly Sales Trend Analysis  
- Product Category Distribution  
- Product Type Performance Analysis  
- Size-wise Sales Comparison  
- Interactive Filters for Day and Month Analysis  

---

## 🛠️ Tools & Skills Used  
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Data Cleaning & Transformation  
- Slicers & Interactive Filters  
- KPI Reporting  
- Business Data Analysis  
- Dashboard Design & Visualization  

---

## 📈 Key Insights Generated  
- Identified top-selling coffee products based on quantity sold  
- Analyzed customer purchasing patterns by hour and location  
- Compared sales contribution across different product categories  
- Monitored revenue and transaction trends for business growth  
- Evaluated product size performance and customer preferences  

---

## 🎯 Project Objective  
The main objective of this project is to create an interactive business intelligence dashboard that provides actionable insights from coffee shop sales data and supports data-driven decision-making.
